AVP: HUNT // HIVE TCG est un projet fan non commercial, indépendant et non officiel. Il n'est ni approuvé, ni sponsorisé, ni produit par les titulaires des franchises auxquelles il fait référence.

Cette mention est également affichée de façon visible dans le pied de chaque écran de l'application publique.

## Actifs inclus

- Les 158 illustrations de cartes et les 16 scènes du jeu sont des créations originales générées avec OpenAI ImageGen sous une direction artistique propre au projet. Elles sont publiées uniquement sous forme de WebP optimisés, avec dimensions, tailles, provenance et empreintes SHA-256 dans `assets/art/manifest.json`.
- Le code SVG original reste un repli léger lorsque l'appareil est hors ligne avant qu'une illustration demandée ait été mise en cache.
- Les icônes PWA sont créées par `scripts/generate-icons.mjs` à partir de formes géométriques originales.
- Les effets sonores sont synthétisés localement avec Web Audio; aucun enregistrement externe n'est embarqué.
- L'interface, les règles et les descriptions de gameplay sont propres au projet. Les citations reconnaissables, ainsi que les titres de tactique/succès reprenant une accroche officielle, ont été remplacés par des textes originaux dans `src/data.js`.

L'archive HTML historique est conservée à l'identique pour vérifier la provenance. Elle n'est pas incluse dans le build ni servie par le serveur local durci. Elle ne constitue pas la version jouable corrigée.

Le dépôt ne doit recevoir aucun visuel officiel, logo officiel, extrait audiovisuel, police propriétaire, scan de carte, musique, dialogue, texte marketing ou autre fichier protégé copié depuis une oeuvre commerciale. Les compositions ImageGen ne doivent reproduire ni acteur, ni affiche, ni costume, ni accessoire, ni décor officiel identifiable.

Les noms de personnages, créatures, lieux et concepts connus ne sont employés qu'à titre référentiel dans le contexte de ce projet fan. Tous les droits correspondants restent à leurs propriétaires.
