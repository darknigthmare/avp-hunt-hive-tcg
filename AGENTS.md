# Règles de continuation Codex

- Préserver les 158 cartes, les trois decks de départ, les sept raretés, les boosters, la campagne, la sauvegarde et le duel sur trois voies.
- Transformer progressivement le standalone en modules testables sans casser le fichier jouable ni les sauvegardes.
- Utiliser uniquement des visuels et sons originaux ; ne jamais copier d'assets officiels.
- Vérifier chaque passe sur ordinateur et mobile, puis exécuter les tests, le contrôle HTTP et le déploiement Vercel.
- Ce projet est indépendant de Stargate, SNL et Unreal Engine.
